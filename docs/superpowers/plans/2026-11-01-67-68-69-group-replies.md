# #67 #68 #69 Group Replies Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** In family groups, Remi takes only a person's own okay (#67), knows which of its polls
are out and never promises to edit one (#68), and writes Hebrew as Hebrew (#69).

**Architecture:** All three are prompt and context fixes in `messaging/groups/`. #67 adds one
rule to the approval classifier's prompt. #68 lists the group's open polls in the group prompt
(from the existing `open_polls` + `outing_line`) and says a posted poll can't be changed. #69
adds Hebrew vocabulary and a plain who's-free line to the same prompt. One branch, one PR, one
commit per issue, since #68 and #69 both edit `prompt.py`.

**Tech Stack:** Python 3.14, Anthropic Haiku 5.5 via `AnthropicLLM`, pytest evals (`-m eval`).

**Spec:** GitHub issues #67, #68, #69; CLAUDE.md "Product voice".

## Global Constraints

- Describe rules, never quote an eval's wording in a prompt: Haiku copies prompt examples (#67).
- Hebrew is written as Hebrew; a poll is "סקר". No gendered guess about one person (existing
  rule in `prompt.py`).
- No vote counts in the prompt: `PollAnswer` is RLS-scoped per tenant, so a count needs a
  cross-tenant read. Title and time only.
- Evals pass 2 of 3 per case (the CI gate, `.github/workflows/evals.yml`). Every case in
  `tests/evals/test_group_evals.py` must pass that gate after the branch, including the ones it
  doesn't touch.
- Worktree tests need `PYTHONPATH=src`. Lint: `uv run ruff format src tests && uv run ruff check src tests && uv run mypy`.
- After code changes: `PYTHONHASHSEED=0 graphify update .`

## Review Focus

1. **A real okay that mentions someone else** ("fine by me, Mom already said yes"). Still YES:
   the writer gives their own okay. Pinned in Task 1 (`own-okay-mentions-mom` in a new
   `test_still_an_okay`).
2. **A poll whose time has passed.** `open_polls` drops it (`starts_at > now`), so it is not
   listed as open. No new test: the query already filters, `tests/db/test_outings.py` covers it.
3. **A plan change after the poll is out** ("make it 8 instead"). Remi says it'll post a new poll
   (and does) instead of "I'll update it". Pinned in Task 2 (`test_a_change_sets_up_a_new_poll`).
4. **No open polls.** The prompt adds nothing, so Remi can't claim there's none while one is
   being posted this turn. Pinned in Task 2 (`test_group_prompt_lists_open_outings`, empty case).
5. **Hebrew who's-free reply when nobody shares yet.** Plain words, no "תמונה". Pinned in Task 3.
